# 兩數之和

給定 $N$ 個整數 $a_1, a_2, \ldots, a_N$ 與一個整數 $S$，找出一對 $i < j$ 使得 $a_i + a_j = S$。

保證恰好只有一對符合。

## 輸入

第一行兩個整數 $N$、$S$（$2 \le N \le 10^5$，$|S| \le 2 \times 10^9$）。

第二行 $N$ 個整數 $a_i$（$|a_i| \le 10^9$）。

## 輸出

兩個整數 $i$、$j$（$1 \le i < j \le N$），以空白隔開，代表位置（從 1 開始）。

## 提示

$O(N^2)$ 的暴力解會超時，試試用 `dict` 記錄看過的數字。
