# 組合數

給定 $n$、$k$，輸出 $\binom{n}{k} \bmod (10^9 + 7)$。

## 輸入

一行兩個整數 $n$、$k$（$0 \le k \le n \le 10^6$）。

## 輸出

一個整數 $\binom{n}{k} \bmod (10^9 + 7)$。

## 提示

$$
\binom{n}{k} = \frac{n!}{k!\,(n-k)!}
$$

除法不能直接取模。$10^9 + 7$ 是質數，可以把除以 $k!\,(n-k)!$ 換成乘上它的模反元素（見「模反元素」）。

用巴斯卡三角形 $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$ 遞推是 $O(nk)$，會超時。

兩個小於 $10^9 + 7$ 的數相乘可能超過 $2^{53}$，JavaScript 要用 `BigInt`；C++ 要用 `long long`。
