# 猜數字

這是一題**互動題**：你的程式不是讀固定的輸入，而是跟評測的「互動程式」一問一答。

互動程式心裡想了一個整數 $x$（$1 \le x \le N$），請用最多 $30$ 次詢問猜出它。

## 互動方式

1. 先讀入一行整數 $N$（$1 \le N \le 10^9$）。
2. 詢問：輸出一行 `? y`（$1 \le y \le N$），再讀入一行回答：
   - `<`：$x < y$
   - `>`：$x > y$
   - `=`：$x = y$
3. 回答：確定 $x$ 之後輸出一行 `! x`，然後結束程式。

詢問最多 $30$ 次，`!` 不算在內。

建議每次輸出後 flush（C++ 用 `endl` 或 `fflush(stdout)`，Python 用 `print(..., flush=True)`）。本系統不 flush 也收得到，但其他評測系統多半會因此卡住。

## 範例

範例中 $N = 10$、$x = 7$；`→` 是你的程式輸出，`←` 是互動程式的回答。

## 提示

二分搜尋：每次問範圍的中間，依回答把範圍砍半。$2^{30} > 10^9$，30 次一定夠。
